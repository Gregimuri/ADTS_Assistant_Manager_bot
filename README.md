# Помощник менеджера

Telegram-бот для менеджеров ADTS: счета по ЕММ и ТО, справка по торговым точкам, выгрузка регионов в Excel и автоматический отчёт по расходным материалам ДО.

Данные читаются из публичной Google-таблицы [«База для бота»](https://docs.google.com/spreadsheets/d/1sRy5VuFGEWsh_RZCGUkWKyKcLP8i6dO-F1smi4ok4Mk/edit).

## Возможности

| Функция | Описание |
|--------|----------|
| **Счёт ЕММ** | Расчёт выезда по листу ЕММ: устройства, прошивки, кубики |
| **Счёт ТО** | Счёт по листу ТО со ссылками на задачи Bitrix |
| **Инфо ТТ** | Название, регион, адрес и менеджер по справочнику проектов |
| **Передать регионы** | Excel-файл по выбранным проектам, менеджеру и регионам |
| **Отчёт по ДО** | Хэштег `#ДО` — предпросмотр в личке с подтверждением отправки в группу; по будням в **9:05** и **17:30** МСК — автоматически в группу |
| **Админ-отчёты** | Только для `ADMIN_USER_IDS`: план/отчёт выходов, сборка расходников из Bitrix — с подтверждением в группу `ADMIN_REPORT_CHAT_ID`; по будням **9:00** и **17:30** МСК — автоматически в группу |

## Интерфейс

После `/start` в личке появляется меню:

- **Счёт ЕММ** · **Счёт ТО**
- **Инфо ТТ** · **Передать регионы**
- **Помощь**

Бот просит список ТТ (каждое название с новой строки). Отмена — кнопка **Отмена**, возврат в меню — **Меню**. Старый способ через хэштеги тоже работает.

Команды `/help` и `/menu` показывают справку. В группах клавиатура скрывается — используйте хэштеги со списком ТТ в одном сообщении.

## Хэштеги

### `#СчетЕММ`

```
#СчетЕММ
Начинатель
Сахарозаводчица
```

Бот ищет каждую ТТ в колонке `name`, группирует плееры по `objectNumber` и считает работы:

- **ЕММ** — устройства со статусом не «не ставить», кроме строк «Ничего не делать»
- **прошивки** — `Перепрошить = прошить`
- **кубик** — `Обновить Кубик = обновить`

Если та же ТТ есть на листе **ТО** и в «Вид работ» есть слово «ЕММ», в ответ подставляется ссылка на задачу Bitrix.

**Тариф:** `1000 + 500 × (ЕММ + прошивки + кубики)` руб. В конце — строка **Итого сумма затрат составляет: … руб.**

### `#СчетТО`

```
#СчетТО
Аптека Методика
Черновицкий МД РзФ
```

Для каждой ТТ: название и адрес, ссылка на Bitrix, вид работ, фактическая стоимость, доп. затраты, итог по ТТ и общий итог.

### `#ИнфоТТ`

```
#ИнфоТТ
Гарантирование
Фасоль 703961
```

- без проекта — поиск по всем листам из справочника;
- если первое слово — название проекта (`Фасоль 703961`) — поиск только на этом листе;
- формат ответа: `Название ТТ - Регион - Адрес - Менеджер`.

### `#ПередатьРегионы`

```
#ПередатьРегионы
Проекты: ММ, МА, ДО
Менеджер: Гарpинич Николай
Регионы: Астраханская обл., Воронежская обл.
```

В личке можно пройти тот же сценарий кнопкой **Передать регионы**. Бот формирует Excel с точками в статусах СМР/сервис (без «Выполнен»).

### `#ДО` (отчёт по расходным материалам)

В личке бот показывает отчёт и предлагает кнопки **Отправить в группу** / **Назад**. В группу попадает только после подтверждения. Доступ к отчёту — только пользователям из `DO_REPORT_USER_IDS` (кнопка **Отчет ДО расходка** видна только им).

По будням в 9:05 и 17:30 МСК отчёт уходит в группу автоматически. Если расходка везде отправлена, сообщение:

> На ближайшие 17 дней расходка по ДО отправлена во все регионы

## Запуск локально

Требуется Python 3.10+.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. В корне проекта:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

3. В `.env` укажите `BOT_TOKEN` и при необходимости `DO_REPORT_CHAT_ID`.
4. Запуск:

```bash
python -m app.main
```

Таблица открыта на чтение — отдельный Google-аккаунт не нужен. Кэш данных: 10 минут (`SHEETS_CACHE_TTL_SECONDS`).

## Переменные окружения

| Переменная | Назначение |
|-----------|------------|
| `BOT_TOKEN` | Токен Telegram-бота |
| `SPREADSHEET_ID` | ID Google-таблицы |
| `DO_REPORT_CHAT_ID` | ID группы для автоматического отчёта ДО (по умолчанию `-4893962129`) |
| `ADMIN_USER_IDS` | Telegram ID администраторов (через запятую) |
| `DO_REPORT_USER_IDS` | Кому доступны `#ДО` и кнопка «Отчет ДО расходка» |
| `ADMIN_REPORT_CHAT_ID` | Группа для админ-отчётов (по умолчанию `-5278414891`) |
| `BITRIX_WEBHOOK_URL` | Webhook Bitrix24 для отчётов по сборке |
| `REPORT_DATA_PATH` | JSON-файл с утренними планами выходов (`data/reports.json`) |
| `SCHEDULED_EXIT_PROJECTS` | Проекты в автоматическом плане/отчёте выходов (через запятую) |
| `DO_ORDER_HORIZON_DAYS` | Горизонт заказа для регионов, дней (17) |
| `DO_MOSCOW_ORDER_HORIZON_DAYS` | Горизонт для Москвы, дней (2) |
| `PRICE_BASE` / `PRICE_PER_UNIT` | Тариф ЕММ (1000 / 500) |

Полный список — в [`.env.example`](.env.example).

### Render (бесплатный Web Service)

На [Render](https://dashboard.render.com/) бот работает как **Web Service** (Free): HTTP на `$PORT`, эндпоинт `/health`, апдейты Telegram через webhook.

Ограничения Free-тарифа:

- сервис засыпает примерно через **15 минут** без HTTP-запросов;
- первый запрос после сна — задержка до минуты;
- **750 бесплатных часов** в месяц на workspace.

Чтобы реже засыпал, настройте ping на `https://<имя>.onrender.com/health` каждые 10 минут (cron-job.org, UptimeRobot).

**Важно:** не запускайте одновременно локальный `python -m app.main` и Render — будет конфликт Telegram.

Создание сервиса: **New + → Web Service**, репозиторий `Gregimuri/ADTS_Assistant_Manager_bot`, ветка `main`, Start Command `python -m app.main`, переменная `BOT_TOKEN`. Либо **Blueprint** из [`render.yaml`](render.yaml).

После деплоя на сервере должны быть установлены зависимости (`pip install -r requirements.txt`) и задан `DO_REPORT_CHAT_ID=-4893962129`.
